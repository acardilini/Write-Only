# Forward Writer

A minimalist, distraction-free web application built to help writers achieve a state of flow by removing the ability to edit. This project is built on the "write-only" principle to force forward momentum.

## Project Goal

This application is being built based on the detailed technical specifications outlined in the [Product Requirements Document (PRD.md)](./PRD.md).

## Technical Overview

* **Framework:** (To be decided - likely React/Vite)
* **Storage:** Client-side `IndexedDB`
* **Features:** Write-only editor, session log, word-count heatmap, Google Drive export.
* **Hosting:** Static (GitHub Pages, Vercel, etc.)
